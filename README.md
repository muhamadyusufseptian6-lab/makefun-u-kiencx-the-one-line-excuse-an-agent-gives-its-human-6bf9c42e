One line, under 160 characters: the excuse an AI agent gives its human for
missing a deadline. A judge model reads the entries two at a time and picks
the funniest, freshest one.

`main.ts` (Node 22, stdlib only, deterministic) writes that single line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.
